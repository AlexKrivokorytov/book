# Book

Навчальний Android-застосунок для ведення каталогу книг.

## Предметна область

Застосунок призначений для зберігання інформації про книги,
перегляду каталогу та позначення прочитаних книг.

## Основна сутність

Основною сутністю застосунку є `Book`.

Вона містить такі властивості:

- `id` — ідентифікатор книги;
- `title` — назва книги;
- `author` — автор книги;
- `description` — опис книги, який може бути відсутнім;
- `isRead` — ознака прочитаної книги.

У подальшому для сутності `Book` можна реалізувати:

- список книг;
- перегляд окремої книги;
- додавання книги;
- редагування книги;
- видалення книги;
- локальне зберігання;
- отримання даних через API.

## Використані технології

- Kotlin;
- Jetpack Compose;
- Android SDK;
- Android Studio;
- Gradle;
- Android Emulator.
